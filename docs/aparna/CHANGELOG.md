# CHANGELOG — Aparna's English Coaching CRM

Our product and planning changes only. (Root `CHANGELOG.md` is upstream Atomic CRM releases and is regenerated by a script.) Newest first.

## 0.5.0-m5 — 2026-11-27 (M5 Pilot readiness)

Added

- Quick add enquiry on Today when the CRM is still empty, above the onboarding steps.
- `docs/aparna/COUNSELLOR-GUIDE.md`: a one-page guide to a day in the CRM.

Changed

- The admissions importer is the only CSV import: the parents-only and companies imports are gone from the Parents and Companies pages and from the onboarding steps (a parent imported without an admission never showed on Today or the board).
- The browser tab, the installed app name and the first-account sign-up heading say "Aparna's English Coaching" instead of "Atomic CRM".

Fixed

- Every `Deploy` run now sets the edge function secret `SB_PUBLISHABLE_KEY`; without it, inviting or disabling staff and merging parents failed in production with 401.

## 0.4.0-m4 — 2026-11-27 (M4 Import and Today quick-add)

Added

- Import admissions from one CSV (board → Import CSV; sample downloadable): parent, phone, country, child, grade, board, course, source, stage, next follow-up, trial time, note, fees, lost reason. Enrolled rows become current students with their fees; other stages become enquiries; an open row without a follow-up gets tomorrow 10:00 IST; a known phone links the existing parent.
- The import checks every row first: if any row has a problem, nothing is imported and the dialog lists each row number with its reason. If the import stops midway (e.g. network), it says which row it stopped at; importing the same file again skips the rows already imported.
- Quick add enquiry on Today, the same button as on the board.

Changed

- The admissions import no longer uses the upstream deal columns (name, company, categories, amount, closing date).

Fixed

- "Forgot password?" emails now link to the sign-in callback page (`/auth-callback.html`), so the reset opens the set-password screen instead of the login page. The production Supabase Redirect URLs must list that page.

## 0.3.0-m2 — 2026-11-27 (M2 Capture and discipline)

Added

- Quick add enquiry on the Admissions board: parent name, WhatsApp number (any form, normalised; country and time zone guessed, time zone editable), child details and a note create the parent and an Enquiry due in 2 hours. A known number links the existing parent and warns.
- Moving a card on the board asks for what the stage needs: a lost reason (Lost), the trial time (Trial booked), fee amount, period and next due date (Enrolled), and a next action when an admission without one goes back to an open stage.
- Board cards show the child, course, next action (red and "overdue" when past) and days in stage.

Changed

- The admission form shows child fields (name, grade, board, course, source), next action, trial time, fee fields and, for Lost, the reason; the name field is hidden and follows the child's name. A new admission starts with a next action tomorrow; an open admission cannot be saved without one.
- Demo mode no longer fails when an admission has no company.
## 0.2.0-m3 — 2026-11-27 (M3 Today and one-tap WhatsApp)

Added

- Today is the landing page on desktop and phone: New (minutes waiting), Follow-ups due, Trials today and tomorrow (IST and the parent's time), Payment pending, Fees due in 3 days or overdue, and a This-week strip (enquiries, median first response, trials, enrolled, lost by reason). Tapping a row opens the admission.
- One-tap WhatsApp from Today rows and the admission page: 9 templates open WhatsApp with the message filled in; "Sent?" logs a note, the first response and the next follow-up. Payment link and fee reminder ask for the Razorpay link first. Disabled with a reason when the parent opted out.
- "Mark fee paid" on fee rows and the admission page; a second tap on a stale screen changes nothing and says it was already marked.
- The Parent form has a "WhatsApp messages allowed" switch.

Changed

- The fee-paid note now records the amount (`mark_fee_paid`, one migration).

## 0.1.0-m1 — 2026-11-24 (M1 Foundation)

Added

- MVP schema (one migration): admission child, follow-up and fee fields; parent country, time zone, WhatsApp number and opt-in; next-action, lost-reason, fee and phone checks; stage trigger; two-staff cap; `mark_fee_paid`; pgTAP specs run in CI.
- Domain config: stages Enquiry to Lost, task types, courses (editable in Settings), boards, sources, lost reasons, INR.
- Parents and Admissions CSV export with the new fields; realistic demo data (Indian and foreign families, every stage, fees).

Changed

- UI says Parents, Admissions and Today; Companies is hidden from the menu; an admission no longer needs a company; Settings shows stages read-only.
- Parent merges keep the WhatsApp number and any opt-out.
- The Deploy workflow only deploys the database and edge functions (Vercel serves the app).
